# ⚽ FutbolMax - Site de Futebol

Um site completo e moderno sobre futebol com resultados, notícias, tabelas de classificação e informações sobre times.

## 📋 Funcionalidades

- **📊 Resultados em Tempo Real**: Acompanhe os últimos resultados dos jogos
- **📰 Notícias em Destaque**: Leia as principais notícias do futebol
- **🏆 Tabelas de Classificação**: Veja a posição dos times na Série A
- **⚽ Informações sobre Times**: Detalhes sobre os principais clubes brasileiros
- **📱 Design Responsivo**: Funciona perfeitamente em celulares e desktops
- **🎨 Interface Moderna**: Layout atraente e fácil de usar

## 🚀 Como Usar

1. Clone o repositório:
```bash
git clone https://github.com/Pedrin03110/site-futebol.git
```

2. Abra o arquivo `index.html` no seu navegador

3. Explore as seções:
   - **Resultados**: Veja os últimos jogos
   - **Notícias**: Fique atualizado com as notícias
   - **Tabelas**: Confira a classificação dos times
   - **Times**: Conheça informações dos principais clubes
